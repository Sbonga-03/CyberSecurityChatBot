# CyberSecurityChatBot

## 📌 Overview
This project is a **C# console-based chatbot** designed to educate users about important cybersecurity topics such as phishing, malware, password safety, and safe browsing practices.

The chatbot provides an interactive and user-friendly experience using text, voice, and visual elements to simulate a real conversation.

---

## 🎯 Objectives
- Promote cybersecurity awareness
- Provide quick and simple explanations of key concepts
- Create an engaging and interactive console application
- Demonstrate clean code structure and programming concepts

---

## 🚀 Features

### 🔊 Voice Greeting
- Uses `SpeechSynthesizer` to greet the user when the application starts

### 🎨 ASCII Art Logo
- Displays a cybersecurity-themed ASCII banner at launch

### 👤 Personalized Interaction
- Asks for the user’s name
- Responds using the user’s name throughout the conversation

### 💬 Chatbot Response System
- Answers questions about:
  - Malware
  - Phishing
  - Password safety
  - Firewalls
  - Safe browsing
- Uses keyword matching for responses

### ⚠ Input Validation
- Handles:
  - Empty input
  - Unknown questions
- Provides helpful fallback messages

### 🖥 Enhanced Console UI
- Uses:
  - Colored text
  - Dividers and borders
  - Structured layout
- Simulates a real chat experience

### 🧱 Code Structure
- Organized into multiple classes:
  - `Program` → Entry point
  - `ChatEngine` → Controls chatbot flow
  - `ResponseService` → Handles responses
  - `UIHelper` → Manages console display

---

## 🛠 Technologies Used

- .NET Console Application
- `System.Speech.Synthesis`
